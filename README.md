# StudyBuddy AI

## Project Overview

StudyBuddy AI is a beginner-friendly study assistant designed to help students learn C++ Object-Oriented Programming (OOP).

It provides simple explanations, real-life examples, C++ code examples, quizzes, and flashcards to support learning and revision.

## Features

- Explain C++ OOP concepts in simple language
- Search topics and match questions to relevant concepts
- View real-life examples and C++ code
- Copy code examples
- Take quizzes and view scores
- Practice with flashcards

## Technologies Used

- HTML — webpage structure
- CSS — styling and layout
- JavaScript — interactive features and learning logic

## How to Run

1. Download or open the project folder.
2. Open `index.html` in a web browser.
3. Choose a learning mode and start studying.

## Current Limitations

The current version uses predefined explanations, examples, questions, and JavaScript matching logic. It does not yet connect to a live AI model or external AI API.

## Future Improvements

- Integrate a live AI model through a secure backend
- Add more programming subjects
- Store learning progress
- Generate personalized practice questions

## Project Goal

To make programming concepts easier to understand and revise through a simple, interactive learning experience.
